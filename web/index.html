Connection & trust

Connected Sepolia wallet preferred. Otherwise, browser-direct public RPCs. Every snapshot must match block hashes from two independent RPC peers; mismatch means unavailable. No server proxy.

A custom RPC joins the peer set but never replaces the two-peer cross-check. Mainnet and undocumented v9 transactions stay disabled.

Activity

Saved in this browser, across profiles. Switching profiles cannot cancel a wallet popup or a broadcast transaction. Receipt reads retry; transactions never do. Final status requires 12 confirmations and public-RPC block agreement.
